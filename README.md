# The Most Boring Object, Reviewed in One Line

A one-line review of a doorstop, the dullest everyday object in the house.
It has held the same door open since 2019 without a sick day, a raise, or
one LinkedIn post about the grind.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (deterministic, no network, no
randomness).

## The line

> Five stars. It's held the same door open since 2019 without a sick day, a raise, or one LinkedIn post about the grind.
